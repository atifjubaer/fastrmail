# FastrMail — Coolify Official Template

This folder contains the template configuration for submission to [Coolify](https://github.com/coollabsio/coolify).

## Files Included

- `docker-compose.yaml`: Compose definition using Coolify's `coolify.tcp.port.*` labels for TCP proxying.
- `service.yaml`: Service catalog metadata.

## Submission Instructions

1. Fork https://github.com/coollabsio/coolify
2. Add `templates/compose/fastrmail.yaml` using the contents of `docker-compose.yaml`.
3. Submit a Pull Request: `Service: FastrMail — Enterprise Mail Server`.
